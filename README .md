# 🇰🇪 Kenya Public Debt & Fiscal Sustainability Analytics Dashboard

## 📌 Project Overview

This project delivers a comprehensive fiscal sustainability and sovereign debt analytics solution built using Python and Power BI. The analysis leverages historical fiscal datasets from the Central Bank of Kenya (CBK) to evaluate Kenya’s public debt trends, debt sustainability, revenue performance, expenditure structure, and fiscal risk exposure.

The dashboard transforms raw fiscal data into executive-level insights capable of supporting:

* Fiscal policy evaluation
* Debt sustainability monitoring
* Sovereign risk assessment
* Public finance analysis
* Treasury-style reporting

---

# 🎯 Project Objectives

The main objective of this project was to build an institutional-grade analytics dashboard capable of answering key fiscal questions such as:

* How has Kenya’s public debt evolved over time?
* What is the relationship between debt and government revenue?
* Is debt growth accelerating faster than revenue growth?
* How sustainable are Kenya’s fiscal operations?
* What proportion of debt is domestic versus external?
* How much revenue is consumed by interest payments?
* What are the major expenditure components?
* What fiscal risks are emerging over time?

---

# 📂 Dataset Sources

The project uses historical fiscal datasets sourced from the Central Bank of Kenya (CBK), including:

* Public Debt Data

The datasets contain:

# ⚙️ Python Data Engineering Workflow

The project started with extensive fiscal data engineering and preprocessing in Python.

## Key Steps Performed

### 1️⃣ Data Extraction

* Imported multiple CBK fiscal datasets
* Loaded Excel files into Pandas DataFrames

### 2️⃣ Data Cleaning

* Removed null rows and metadata rows
* Renamed inconsistent column headers
* Converted fiscal periods into proper datetime format
* Standardized numeric columns
* Handled missing values

### 3️⃣ Data Transformation

* Merged debt, revenue, and expenditure datasets
* Built a unified fiscal master dataset
* Created analytical columns and derived indicators

### 4️⃣ KPI Engineering

Created advanced fiscal indicators including:

* Fiscal Deficit
* Debt-to-Revenue Ratio
* Interest Burden Ratio
* Debt Growth Rate
* Revenue Growth Rate
* Expenditure Growth Rate
* Primary Balance
* Debt Sustainability Risk Score
* Domestic Debt Ratio
* External Debt Ratio

# 📌 Key Fiscal Insights Discovered

## 📈 Rising Public Debt

Kenya’s public debt has increased significantly over time, reflecting sustained borrowing requirements and fiscal financing pressure.

## ⚠️ Elevated Debt Sustainability Risk

The Debt-to-Revenue Ratio remains high, indicating increasing fiscal vulnerability and reliance on debt financing.

## 💰 Growing Interest Burden

Interest payments continue consuming a larger portion of government revenue, reducing fiscal flexibility.

## 🏛️ Heavy Recurrent Expenditure

Government spending remains heavily concentrated in recurrent expenditure obligations.

## 🌍 External Debt Exposure

External debt remains substantial, exposing the economy to foreign exchange and refinancing risks.
